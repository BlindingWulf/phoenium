# Phoenium

Phoenium is a Fabric 26.2 dedicated-server regionized multithreading engine.

Stage 3 serial correctness is frozen within its declared supported scope. Stage 4
regional world services are in development, with one gameplay worker and parallel
gameplay disabled. See [current work](docs/STAGE4_CURRENT_WORK.md), the
[Stage 3 closure](docs/STAGE3_CLOSURE_REPORT.md), and [roadmap](docs/ROADMAP.md).
